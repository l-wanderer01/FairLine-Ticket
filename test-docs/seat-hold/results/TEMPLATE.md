# 좌석 선점 테스트 실행 결과

상태: NOT_RUN

## 실행 정보

| 항목 | 값 |
| --- | --- |
| run ID / 실행자 | 미입력 |
| 시작·종료 시각 / 시간대 | 미입력 / Asia/Seoul |
| 코드 커밋 / 미커밋 변경 | 미입력 |
| 케이스 문서 버전 / 적용 정책 | 미입력 |
| JDK·Redis·PostgreSQL / 도구 버전 | 미입력 |
| 서비스 인스턴스 수 / routing | 미입력 |
| fixture 버전 / 별칭→실제 ID | 미입력 |
| TTL 변경·스케줄러·stub·hook 설정 | 미입력 |

## 케이스별 결과

| 케이스 / 변형 | 반복·요청 수 | 상태 | 기대 결과 / 실제 결과 | 증거 경로 | 결함 ID / 보류 이유 |
| --- | --- | --- | --- | --- | --- |
| TC-XX | 미입력 | NOT_RUN | 미입력 | 미입력 | 미입력 |

## 증거

- 요청별 응답·시각·사용자·대상 인스턴스: 미입력
- Redis before/after owner·PTTL·holds·access·active: 미입력
- DB before/after 예약·항목·좌석, 위반 조회 결과: 미입력
- 관련 로그·업무 이벤트·점수 변화: 미입력
- 경쟁 barrier/hook 도달 또는 장애 주입 증거: 미입력

JWT·비밀번호·API 토큰·실제 PG 키는 첨부하지 않는다.

## 결함 기록 (결함별 복사)

- 결함 ID / 우선순위 / 관련 케이스·불변 조건:
- 재현 환경·사전 조건:
- 최소 재현 순서:
- 기대 동작:
- 실제 동작·영향:
- 증거:
- 원인 분석 (가설/확인 구분):
- 수정 커밋 또는 정책 결정:
- 재검증 run·결과:
- 관련 회귀 케이스·결과:

## 실행 판단

- PASS / FAIL / BLOCKED / NOT_RUN 건수:
- 확인된 불변 조건 위반:
- 미결정 정책과 환경 제약:
- 다음 실행에서 준비할 항목:

실행하지 않은 케이스와 증거 없는 항목을 PASS로 집계하지 않는다.
